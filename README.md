# Sensible

Et top-down fodboldspil i browseren, inspireret af Sensible Soccer. Spil Premier League eller Champions League (ligafasen 2026/27) på computer eller mobil.

**Aktuel version: Sensible 0.18.0** – se [CHANGELOG.md](CHANGELOG.md).

## Styring

| | Computer | Mobil |
|---|---|---|
| Løb | piletaster / WASD | træk på venstre side |
| Aflever / skyd | Mellemrum (kort = aflever, hold = skud) | SKYD-knap (højre side) |
| Sigtet aflevering | X / Shift | PASS-knap |
| Stående tackling | PASS tæt på modstanderen med bolden | PASS-knap |
| Glidetackling | Mellemrum uden bold | SKYD uden bold |
| Førstegangsskud | tryk SKYD, før bolden når spilleren | samme |
| Hjørnespark | sigt med retning, SKYD/PASS | samme |
| Auto-aim | Skud mod målet får hjælp til at ramme (afhænger af sværhedsgrad) | samme |
| Instant skud | Vælges i menuen: ét tryk på SKYD giver straks et hårdt skud | samme |
| Hovedstød / volley | SKYD lige før en høj bold når spilleren (hold en retning for at sigte) | samme |
| Skru | hold en retning mens bolden er i luften | samme |

## To spillere på samme tastatur

Vælg "2 spillere" i menuen under holdvalget.

| | Spiller 1 (hjemmehold) | Spiller 2 |
|---|---|---|
| Løb | piletaster | WASD |
| Skyd | 0 (numpad) | G |
| Aflever | , (numpad) | H |

## Kør det

Åbn `index.html` i en browser. Der er ingen afhængigheder eller build-trin.

## Gør det spilbart online (GitHub Pages)

1. Læg filerne i et repository med navnet `sensible`.
2. Repository → Settings → Pages → Source: `main` branch, mappen `/ (root)`.
3. Spillet ligger nu på `https://<dit-brugernavn>.github.io/sensible/`.
